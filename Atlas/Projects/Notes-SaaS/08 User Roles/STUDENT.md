# STUDENT

## Capabilities

- Authenticate
- Browse active subjects/topics
- Read published notes
- Search published notes
- Create/delete own bookmarks
- Download notes locally
- Read downloaded notes offline
- View/edit own display name

## Restrictions

- Cannot create/update/delete subjects, topics, or notes.
- Cannot promote own role.
- Cannot access admin UI successfully.

## Security

Firestore rules enforce the restrictions independently of UI guards.
