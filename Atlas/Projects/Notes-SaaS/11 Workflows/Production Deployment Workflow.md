# Production Deployment Workflow

1. Build with production environment variables.
2. Validate TypeScript, lint, tests, and production build.
3. Deploy Firestore rules/indexes.
4. Deploy Firebase Hosting.
5. Verify SPA deep links.
6. Verify Auth, Firestore, Admin, PWA, offline and core user flows.
7. Keep `.env` out of git.
